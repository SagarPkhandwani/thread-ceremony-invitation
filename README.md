# आरव का यज्ञोपवीत संस्कार

एक सुंदर, मोबाइल-फ्रेंडली हिंदी निमंत्रण वेबसाइट। `index.html`, `styles.css` और `script.js` सीधे संपादित किए जा सकते हैं।

## अपनी जानकारी बदलें

`index.html` में **आरव**, **शर्मा परिवार**, माता-पिता के नाम, तारीख, समय, स्थल और पता खोजकर अपनी जानकारी लिखें। Google Maps लिंक और WhatsApp निमंत्रण का संदेश भी वहीं बदलें।

`script.js` में `eventAt` वाली तारीख और समय बदलें। भारत के लिए समय-क्षेत्र `+05:30` रखें; उदाहरण: `new Date('2027-01-17T09:30:00+05:30')`।

संगीत के लिए अपनी MP3 फ़ाइल `assets/ceremony-music.mp3` नाम से रखें। संगीत बटन दबाने पर ही चलेगा।

## GitHub Pages पर प्रकाशित करें

1. इस रिपॉज़िटरी में **Settings → Pages** खोलें।
2. **Deploy from a branch** चुनें।
3. Branch `main` और folder `/(root)` चुनकर **Save** दबाएँ।
4. Pages तैयार होने पर Settings → Pages में दिखने वाला लिंक साझा करें।

यह साइट RSVP जानकारी जमा नहीं करती।
