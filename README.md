# सुगंध परिवार का यज्ञोपवीत संस्कार

मोबाइल-फ्रेंडली हिंदी निमंत्रण वेबसाइट। इसमें 12–13 दिसंबर 2026 का दो-दिवसीय कार्यक्रम, पाँच पौत्रों के नाम, मेहंदी-संगीत, यज्ञोपवीत संस्कार, भोज, बारात, स्वागत-समारोह और दोनों स्थलों के मानचित्र शामिल हैं।

## कार्यक्रम विवरण बदलें

- `index.html` में नाम, परिवार, रिश्तेदार, कार्यक्रम और स्थल बदलें।
- `script.js` में `eventAt` की तारीख और समय बदलें। भारत का समय-क्षेत्र `+05:30` रखें।
- मानचित्र लिंक और WhatsApp निमंत्रण `index.html` में हैं।
- संगीत के लिए `assets/ceremony-music.mp3` रखें।

पर्ची में वर्ष नहीं दिया गया था, इसलिए वेबसाइट में आने वाला दिसंबर **2026** रखा है। तीसरे पौत्र का हस्तलिखित नाम “Laggush” पढ़ा गया है और वेबसाइट में “लग्गुश” लिखा है—साझा करने से पहले इन दोनों विवरणों की पुष्टि कर लें।

## GitHub Pages पर प्रकाशित करें

यह रिपॉज़िटरी GitHub Pages से प्रकाशित है। GitHub पर बदलाव करने के लिए फ़ाइल खोलें, पेंसिल **Edit** चुनें और बदलाव के बाद **Commit changes** दबाएँ। कुछ क्षणों में वही सार्वजनिक साइट अपडेट हो जाएगी।

स्थानीय पूर्वावलोकन के लिए `index.html` ब्राउज़र में खोलें।
